The geometry component, `level_set_topology`, specifies a level-set field defined at the nodes of the provided input mesh_name.
The zero-valued iso-surface of the level set field represents the material boundary, separating solid material (greater than zero) from void (less than zero).
The solid material region is used to produce a conforming finite element mesh for analysis.

The level set topology component specifies that the geometry of the optimization problem will be defined by a level set field over the design domain.
The level set values at each node of the design domain mesh make up the design variables used to optimize the geometry and range between a user-defined min and max.
The final optimized geometry will be generated by extracting the 0.0 level set iso-volume from the level set field.
The main difference between level set and density parameterizations is that the 0.0 level set iso-volume is cut out of the background mesh at each optimization iteration, resulting in a conforming finite element mesh which is used for objective/constraint calculations.
The level set geometry representation works well for problems where the density approach struggles because of poorly-resolved interfaces.
