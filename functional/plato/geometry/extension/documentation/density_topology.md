The geometry component, `density_topology`, specifies a design domain defined at the nodes of the provided input mesh_name.
The nodal density values range from 0, representing void, to 1, representing solid material.
These densities define an implicit material distribution for finite element analysis.
An explicit representation of the final optimized geometry can be generated by extracting the 0.5 density iso-volume from the density field using the optional parameter `cut_mesh_name`. 

The density topology component specifies that the geometry of the optimization problem will be defined by a density field on the design domain.
The density values at each node of the design domain mesh make up the design variables used to optimize the geometry and range from 0 (no material) to 1 (solid material).
Objective and constraint calculations are done on an implicit representation of the geometry based on this density field.
An explicit representation of the final optimized geometry is generated by extracting the 0.5 density iso-volume from the density field.
As an implicit geometric definition, density topology can be used for many types of optimization problems but tends to not do very well with physics that require a precise/explicit geometry definition for correctness and accuracy.
An example of this would be structural dynamics where intermediate density values (non 0 or 1) or islands of material can lead to incorrect results.
